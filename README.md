## 🤖 About This Project

OldSchoolBro is a Discord bot designed to assist with Old-School Essentials (OSE) tabletop role-playing games. The bot is built with Node.js and the `discord.js` library, and it's designed to be easily extensible with new commands and features.

This project is a portfolio piece that showcases my ability to create and deploy a Discord bot, as well as my passion for tabletop gaming.

## ✨ Key Features

*   **Simple Command Structure:** The bot uses a simple, easy-to-understand command structure.
*   **Extensible:** The bot is designed to be easily extended with new commands and features.
*   **Old-School Essentials Focused:** The bot is designed to be a helpful tool for OSE players and game masters.

## 🛠️ Technologies Used

*   **Runtime:** Node.js
*   **Library:** `discord.js`
*   **Environment Variables:** `dotenv`

## 🚀 Getting Started

To run this bot, you will need:

*   Node.js and npm installed.
*   A Discord account and a Discord server where you have permission to add bots.
*   A Discord bot token.

**To get started:**

1.  Clone this repository.
2.  Install the dependencies:
    ```bash
    npm install
    ```
3.  Create a `.env` file in the root of the project and add your Discord bot token:
    ```
    TOKEN=your-discord-bot-token
    ```
4.  Start the bot:
    ```bash
    node src/index.js
    ```
5.  The bot should now be online and ready to respond to commands in your Discord server.
